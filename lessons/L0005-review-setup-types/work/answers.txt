Trap 2: why int("7") + 1 works, and what would happen without int(...). It works because str 7 gets converted to int before getting added to 1. If 7 still was str than running it will cause TypeError: can only concatenate str (not "int") to str
Trap 3: why bool("False") gives what it gives. It gives True because python is just checking if anything is present inside quotes.
